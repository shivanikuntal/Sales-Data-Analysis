# Sales Data Analysis

## Project Overview

This project analyzes sales data using Python and Pandas to extract key business insights and understand sales performance.

## Objective

The objective of this project is to analyze sales data from a CSV file and identify important sales trends, top-performing categories, countries, and products.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Loaded and explored the sales dataset
- Checked dataset structure and missing values
- Calculated basic sales statistics
- Analyzed key sales KPIs
- Performed product category-wise sales analysis
- Performed country-wise sales analysis
- Identified top-performing products
- Analyzed sales by deal size
- Created bar charts and pie charts
- Extracted key business insights

## Visualizations

- Product Category-wise Sales
- Country-wise Sales
- Top Countries Sales Distribution
- Top Products by Sales
- Sales by Deal Size

## Dataset

The dataset used in this project is the Sample Sales Data dataset available on Kaggle.

**Source:** [Kaggle - Sample Sales Data](https://www.kaggle.com/datasets/kyanyoga/sample-sales-data)

## Conclusion

The analysis helps identify high-performing product categories, countries, and products. These insights can support business decisions related to sales strategy, market focus, and product performance.
